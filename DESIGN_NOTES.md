| 2026-09-19 | M1 · Sidebar width | 216px / 56px **border-box** (README, `w-sidebar`). The prototype's inline `width:216px` is content-box, so it renders 237px / 57px. Nav items are therefore 195px wide instead of 216px. | README wins. |
| 2026-09-19 | M1 · Sidebar icons | Lucide icons in the expanded items and a 36×34 icon rail when collapsed. The prototype shows text only and mono initials. The collapsed rail shows no amber left bar (as in the prototype); `aria-current` marks the active item. | README wins. |

| 2026-09-19 | M1 · WT Live status | Shows "WT Live online" until M5 provides a skin count (`Sidebar.liveSkinCount`). The full "WT Live online · 2,318 skins" wraps to two lines in the 174px card, and does so in the prototype too. | No data before M5. |
| 2026-09-19 | M1 · Italian nav label | `common.nav.queue` in Italian is "Da installare". The screen title and the palette action keep "Coda di installazione". | "Coda di installazione" (126px) truncates next to a two-digit badge (99px available). The author may prefer other wording. |
| 2026-09-19 | M1 · Palette results | Action hints show the section shortcut (1–5, read from `SECTION_KEYS`) instead of the prototype's meaningless "Action". Empty query: 5 actions + 4 vehicles. Otherwise skins → vehicles → actions, case-insensitive substring on label or hint, max 9. Vehicles go to Explore (the vehicle filter arrives in M5), and skins arrive in M5. | README leaves the action hint open. |
| 2026-09-19 | M1 · Palette a11y | ARIA combobox + listbox (`aria-activedescendant`); rows are `role=option` divs, not tab stops. Tab is trapped in the input and focus returns to the opener on close. The input has no outline: the caret plus the highlighted row are the focus indicator in this modal. "No matches" sits in a `role=status` region outside the listbox. The overlay closes on mousedown on itself. | WAI-ARIA pattern; a listbox may only contain options. |
| 2026-09-19 | M1 · Escape layering | Escape inside the palette closes only the palette and stops propagation. Later menus, dialogs and zoom must also close only the topmost layer. | Avoid closing what is underneath. |
| 2026-09-19 | M1 · Toasts | Always-mounted `<section aria-live="polite">`; newest at the bottom; max 4, oldest dropped. Each toast's 6s timer pauses while hovered or focused and resumes with the time left. Keyboard Undo/× hands focus to the next toast or back to where it was. `undo()` runs at most once, never after expiry. | WCAG 2.2.1 (timing adjustable) and focus management. |
| 2026-09-19 | M1 · Ctrl+Z | **New shortcut**: Ctrl/Cmd+Z (outside text inputs) undoes the newest toast that offers Undo. | Keyboard users otherwise have to Tab to the end of the page within 6s. |
| 2026-09-19 | M1 · Drag & drop | Inside Tauri uses `onDragDropEvent` (real OS paths); in the browser falls back to HTML5 events (file names only). A drop with at least one ZIP/RAR/7z → items `analyzing` + switch to Install queue, no toast. A drop with no archive → "Only ZIP, RAR and 7z archives can be added" toast (the prototype's fake `dropped_archive.zip` fallback is not copied). A Tauri `enter` with no file paths does not show the overlay. The overlay also clears on window blur. TODO(M2): don't switch screens during first run. | Real paths are needed by `analyze_archive` (M4). |
| 2026-09-19 | M1 · Kbd / line-height | Kbd, the palette rows and the offline tag use `leading-[normal]` to match the prototype's `font:` shorthand (17px key cap, 35px palette rows). | 1:1 with the prototype. |
| 2026-09-19 | M1 · Motion | Hover color transitions (120ms) use `motion-safe:` variants, as does the toast enter animation (`toastIn`). | README Motion; instant under reduced motion. |
| 2026-09-19 | M2 · Real-world facts | Verified on the author's machine and the WT wiki. Steam's registry `SteamPath` is lower-case with forward slashes. War Thunder (appid 236390) lives in a secondary library listed in `libraryfolders.vdf`. The root holds `launcher.exe` + `win64\aces.exe` (no `aces.exe` at the root) and `content\pkg_main.ver` (e.g. `2.59.0.13`); there is no `version` file. `%LOCALAPPDATA%\WarThunder` can hold only `downloads\` and is not a root. The in-game template folder is `template_<vehicle>` holding `<vehicle>.blk`; the game shows the folder name as the skin name. | DATA_MODEL assumed `aces.exe` at the root and a `version` file. |
| 2026-09-19 | M2 · Game root | Valid root = `UserSkins\` or `launcher.exe` or `aces.exe` or `win64\aces.exe`. Picking `UserSkins`, `win64`, `win32`, `content`, `content.hq` or a file inside the root resolves to the root. Version = `content\pkg_main.ver` (fallback: a root `version` file), shown as major.minor. `set_game_path` creates `UserSkins\` only when the user confirms, and a new root without a version clears the stored one (`SettingsPatch.gameVersion` is a double option on the Rust side). | Real installs. |
| 2026-09-19 | M2 · Detection | Steam roots come from the registry (HKCU `SteamPath`, HKLM `InstallPath`) plus the default path. Libraries come from `steamapps/libraryfolders.vdf` (new and legacy formats), falling back to `config/`. `appmanifest_236390.acf` gives `installdir`. Standalone candidates: `%LOCALAPPDATA%\WarThunder`, Program Files (x86) and Program Files `\WarThunder`, `…\Gaijin\War Thunder`, `C:\Games\WarThunder`. Every source is checked and emits `game://detect` (`checking` → `found`/`notFound`; custom without a saved path → `skipped`, a state added to DATA_MODEL). Result priority: Steam > standalone > custom. Full paths are logged only at debug level. | Each First run row shows a real outcome. |
| 2026-09-19 | M2 · Detection pacing | Real results arrive in milliseconds. The UI reveals them over ~1.2s (Steam at 30%, standalone at 70%, custom at 100%, as in the prototype) and then auto-advances. Events and the command reply may arrive in any order; missing final states are filled in from the reply. | Readable, honest progress. |
| 2026-09-19 | M2 · Onboarding flag | New setting `onboarded` (not in DATA_MODEL). First run shows when `!onboarded && !gamePath`. Finishing, skipping the import or "Skip for now" sets it. While settings load, the shell shows the title bar and an empty ruled main (no sidebar flash). If settings can't be read, the app boots to Explore. | Skipping must not bring First run back every launch. |
| 2026-09-19 | M2 · First run shell | No sidebar. Keys 1–5, `,` and `[ ]` are ignored; Ctrl+K, Esc and Ctrl+Z still work (prototype). Leaving through the palette doesn't set `onboarded`. | Prototype lines 632-638. |
| 2026-09-19 | M2 · First run UI | Past steps ink-3 and future steps ink-5 (README). Confirm card border `amber-60` (README; the prototype uses .5). "Show path" reveals the game root. A folder that is not a game shows an inline `role=alert` message. The "Game folder set" toast appears only for a hand-picked or dropped folder. With 0 existing skins First run finishes right after confirming. Focus moves to each step's heading. | README wins; a11y. |
| 2026-09-19 | M2 · First run drops | While the not-found view is shown, window drops go to it (`ui.folderDrop`) and the overlay reads "Drop the War Thunder folder · FOLDER". During First run otherwise, archives are queued without switching screens, with a new "N archives added to the install queue" toast. | The prototype gave no feedback (WCAG 4.1.3). |
| 2026-09-19 | M2 · Technical animation | 1:1 port of the prototype's drawing. Per-element delays are inline `animationDelay` (data-driven, and it survives the `motion-safe` shorthand); 3D geometry is inline. "UNOFFICIAL TOOL" is end-anchored at x=482 so longer translations stay on the sheet. Below 1280px the stage is scaled to 90%. Reduced motion shows the final frame. | Fits 1100×700; i18n. |
| 2026-09-19 | M2 · Skin scan | One sub-folder of `UserSkins` = one skin. Folders starting with `.` are skipped (Livery's own `.livery\` lives there from M3). The blk is the alphabetically first top-level `*.blk`; its stem is the vehicle code. Attention: `.livery-partial` marker → partialExtract; no blk → noBlk; unreadable blk → **unreadableBlk** (new kind, message carries line:column); root blocks other than `replace_tex`/`set_tex` → unknownBlkBlock; a `to:` texture missing from the folder → missingTexture (a trailing `*` is stripped; without an extension, `.dds` or `.tga`). Origin is `mine` for `template_` folders, otherwise `imported`. The name is the folder name. | Real skin layout. Known limit: a `to:` pointing at a built-in game texture is a false missingTexture. |
| 2026-09-19 | M2 · Vehicle fallback | Codes missing from `src/data/vehicles.json` (embedded in Rust) get name = code, nation from the prefix (`germ_` GER, `us_` USA, `ussr_` USSR, `uk_` GBR, `jp_` JPN, `cn_` CHN, `it_` ITA, `fr_` FRA, `sw_` SWE, `il_` ISR, otherwise **`UNK`**, a new Nation value), type ground when prefixed (naval for ship words), otherwise air. | Heuristic until the M5 datamined catalog. |
| 2026-09-19 | M2 · Library index | `<appData>/library.json` (`{ version: 1, skins }`), atomic writes, tolerant load (corrupt → `.bad`). `scan_user_skins` never writes; `import_skins` upserts by folder name (case-insensitive) and returns the whole index. Ids `s-<hex nanos>-<n>`; not-yet-imported folders are `disk:<folder>`. JSON rather than SQLite because `rusqlite` is not an approved dependency yet (README allows "SQLite (or JSON)"). | Dependency rule in CLAUDE.md. |
| 2026-09-19 | M2 · BLK parser | `library::blk` (reused by M4 archives): `name:type=value` params, blocks, `include`, quotes `"…"`, `'…'`, `"""…"""`, DAGOR `~` escapes, `;`, newline or space separators, `//` and `/* */` comments, BOM, errors with line:col, nesting limit, linear time on hostile input. | Fixture-tested. |
| 2026-09-19 | M2 · Blocking work | Disk-touching commands are `async` and run in `spawn_blocking` through the shared `crate::blocking` helper. | The UI thread never waits on I/O. |
| 2026-09-19 | Tokens | `ink-4` is **#80828a** (handoff #7c7e86): 4.59:1 on bg-3 and 4.63:1 on inputs (was 4.34 and 4.38), and ≥4.76 on bg-1/2/status. The change is invisible to the eye. New tokens: `bg.tile`, `placeholder-thumb`, `placeholder-tile`, `hatch`, `scanline` backgrounds, and the `draw`, `label-in`, `tile-in` animations. | WCAG AA for small text everywhere ink-4 sits. |
| 2026-09-19 | Buttons | At 34px, secondary and ghost buttons use 14px side padding and primary 16px (prototype). | 1:1 widths. |
| 2026-09-19 | M3 · Inactive skins (open decision 1) | An inactive skin's folder moves to `UserSkins\.livery\inactive\<folder>` (atomic rename on the same volume; the game only looks for `<vehicle>.blk` directly inside each `UserSkins\<folder>`, so it ignores `.livery`). The folder name, which the game shows as the skin name, is preserved. `active` is whatever the disk says. | Instant toggles and no renamed skins in game; a `_` prefix would still show in game under a changed name. |
| 2026-09-19 | M3 · Backups | Before a delete, the folder moves to `UserSkins\.livery\backups\<backupId>\<folder>` (same volume, instant Undo). With "Keep a backup" off the backup is **ephemeral**: Undo-only, not listed, purged after 60s. Kept backups expire after `backupDays` (30). Purges run at launch and at the start of every library command. `restore_backups` puts skins back where they were with their original id; on a name clash it restores as `<folder> (n)`. | CLAUDE.md: every regrettable change is undoable with a backend backup. |
| 2026-09-19 | M3 · Library index v2 | `library.json` = `{ version: 2, skins, collections, activeCollectionId, backups }` (v1 loads transparently). All changes go through `LibraryStore::transact`, which journals renames and undoes them if anything fails, so disk and index never disagree. Every folder name from the index is validated before building a path (rejects `..`, trailing dots/spaces, hidden names), so a tampered index can't touch anything outside `UserSkins`. Re-check refreshes and prunes the index (not when `UserSkins` is missing). | Data safety. |
| 2026-09-19 | M3 · Partial failures | Toggle/activate move what they can; clashing folders are skipped and reported in one error (conflict > io > notFound, names one per line in `detail`). Delete is all-or-nothing. The UI re-reads the index and collections after any such error. | Clear outcome, consistent UI. |
| 2026-09-19 | M3 · Export | Copies each skin folder into a folder the user picks (`<folder> (n)` on clashes). ZIP export waits for approval of a zip crate. | Dependency rule. |
| 2026-09-19 | M3 · Collections | Stored in the index. Activating a collection makes exactly its skins active (folders moved as above); nothing is deleted. Delete collection and Remove member are undoable (restore / re-add). Activation is a plain toast (spec). Open question: `activeCollectionId` stays set after manual toggles, and an Undo of a deleted active collection doesn't re-activate it. | README §5. |
| 2026-09-19 | M3 · Hangar interaction | Until the skin detail exists (M5), clicking a card or pressing Enter/Space on it toggles selection; Shift extends a range. The checkbox is not a tab stop (the card is). Bulk actions apply only to selected skins that the current filters show. Active toggles are optimistic. The bulk bar is a `role=toolbar` placed before the list in DOM order; Escape clears the selection. The card's `role=button` is a full-card hit area under the inner controls (avoids nested-interactive). | No detail screen yet; keyboard efficiency; a11y. |
| 2026-09-19 | M3 · Hangar virtualization | TanStack Virtual over a flattened row model (group headers + card lines chunked by container width), with a pinned group header overlay. Measured with 1,000 skins (`pnpm dev:mock` + `?many=1`): ~20 cards in the DOM, p95 frame 14ms while scrolling. | BUILD_PLAN M3 acceptance (60fps). |
| 2026-09-19 | M3 · Hangar filters | Chips list only values present in the hangar, plus the currently set one. The "any" labels are per chip so Italian agrees in gender: "Tutte le nazioni", "Tutti i tipi", "Tutte le origini". Nation display names are under `hangar.nation.*`. | Natural Italian. |
| 2026-09-19 | M3 · Contrast tweaks | Hangar: "Inactive" and sizes on selected rows use ink-3 (ink-4 on bg-4/bg-hover is 4.2–4.4:1); group codes use ink-4. Unchecked checkbox border ink-5 (was line-4, 1.5:1) and the off switch track gets an ink-5 inner ring: both reach 3:1 non-text contrast (WCAG 1.4.11). | AA. |
| 2026-09-19 | M3 · UI primitives | `Menu` (APG menu button: arrows, Home/End, type-ahead, Escape closes only the menu, Tab closes), `ChipDropdown` (`labelValue` for Explore, `label` for Hangar; amber-60 border when set in both), `SegmentedControl` (radiogroup, roving tabindex), `Checkbox` (`role=checkbox`, 24px hit halo), `Switch`, `TextInput` (Escape clears a non-empty search).
