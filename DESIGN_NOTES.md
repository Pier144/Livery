# Design notes (living document)

Record here every decision taken during implementation that the handoff left open, plus any token or copy added.

| date | topic | decision | why |
|---|---|---|---|
| 2026-09-19 | Repo layout | Handoff docs moved to `design_handoff_livery/`; `CLAUDE.md`, `DESIGN_NOTES.md` and `tokens/` stay at the root (the app reads/updates them). App scaffolded at the root. | Kickoff assumed this layout; keeps design refs apart from code. |
| 2026-09-19 | Tooling versions | React 18.3, TypeScript 5.9 (not 7), Vite 8, Vitest 5, Tailwind 3.4, Tauri 2.11, Zustand 5, TanStack Query 5 / Virtual 3, react-i18next 17, lucide-react 1.x. | Stack fixed by CLAUDE.md; TS 5.9 chosen over the new native TS 7 for ecosystem compatibility. |
| 2026-09-19 | Dependencies approved beyond the stack | jsdom, @testing-library/jest-dom, @testing-library/user-event, axe-core (dev). Fonts copied from `geist@1.7.2` and `@fontsource/ibm-plex-mono@5.3.0` (not kept as deps). Rust: serde/serde_json (Tauri template), tracing + tracing-subscriber (BUILD_PLAN M0). | Approved by the author on 2026-09-19. |
| 2026-09-19 | Tauri plugins deferred | dialog, opener (shell-open), os, fs and updater are **not** added in M0. M1 uses only core window/webview APIs. Each plugin will be proposed in the milestone that needs it (dialog/opener → M2, updater → M6, which also needs a signing key). | Author did not approve the plugin group yet. |
| 2026-09-19 | Fonts | Geist 400/500/600 (static woff2); IBM Plex Mono 400/500 in latin, latin-ext and cyrillic subsets with `unicode-range`. `↵` (U+21B5) is not in Plex Mono's latin subset and falls back to the system mono. | Cyrillic needed for the Русский language option. |
| 2026-09-19 | Tokens added | `bg.scrim` rgba(19,20,22,.85) (drop overlay), `bg.skel` #222327 (skeleton title bar, from prototype), `backgroundSize.shimmer` 200% 100%, `backgroundPosition.grid` -1px -1px, `fontSize.heading-lg` 18px/1.3 500 (empty-state and dialog titles). | Values used by the prototype but missing from the token file. |
| 2026-09-19 | Ruled grid utility | `bg-grid` emits image + 28px size + -1px position in one class (three token groups share the key). | One class per content area. |
| 2026-09-19 | Settings shortcut | Keys 1–5 switch sections (5 = Settings) and `,` also opens Settings, matching the sidebar hint. `[` and `]` both toggle the sidebar (prototype behaviour). | README lists "1–5" but the sidebar shows `,` for Settings. |
| 2026-09-19 | Sidebar preference | `sidebarOpen` is persisted in localStorage (`livery.ui`); nothing else in the UI store persists. | Per-user convenience; not worth a backend setting. |
| 2026-09-19 | Settings file | `<appData>/settings.json`, written atomically (temp + rename). Unknown fields ignored, missing fields defaulted; a corrupt file is renamed to `settings.json.bad` and defaults are used. | Never crash on a bad settings file. |
| 2026-09-19 | App identifier | `app.livery.desktop`. | Neutral reverse-DNS id; change before the first public release if a domain is registered. |
| 2026-09-19 | Vehicle list | `src/data/vehicles.json` holds a 9-vehicle placeholder seed (the prototype's sample vehicles) for the palette until M5 ships the datamined list. | BUILD_PLAN open decision 3 is taken in M5. |
| 2026-09-19 | App icon | Amber dot (#F7A224 ≈ oklch(0.78 0.16 70)) with glow on a graphite tile with a faint ruled grid; source `src-tauri/icons/app-icon.svg`. | Design system names the concept but has no asset. |
| 2026-09-19 | M1 · Dividers | Inner dividers use `line-2`. The prototype uses an untokenised #222327 for these (e.g. the title-bar bottom border), but the README specifies line-2. | README wins. |
| 2026-09-19 | M1 · Title bar height | `box-content h-titlebar`: 38px of content plus a 1px border, 39px in total, as in the prototype. The 26px controls then sit on whole pixels (y=6). | Crisp rendering; matches the prototype. |
| 2026-09-19 | M1 · Window controls | Lucide `minus` / `square` / `x`. When the window is maximized the middle button keeps `square` but its label/tooltip becomes "Restore". Native-style `title` tooltips. Failures of the native call are swallowed. The maximized state is re-read on resize and the newest answer wins. | README icon list; out-of-order `isMaximized()` answers used to show the wrong label. |
| 2026-09-19 | M1 · Drag region | `data-tauri-drag-region` sits on the header and every non-interactive wrapper/text in it, never on buttons. Double-click maximizes natively. | Tauri 2 applies the attribute only to the element that carries it. |
| 2026-09-19 | M1 · Sidebar width | 216px / 56px **border-box** (README, `w-sidebar`). The prototype's inline `width:216px` is content-box, so it renders 237px / 57px. Nav items are therefore 195px wide instead of 216px. | README wins. |
| 2026-09-19 | M1 · Sidebar icons | Lucide icons in the expanded items and a 36×34 icon rail when collapsed. The prototype shows text only and mono initials. The collapsed rail shows no amber left bar (as in the prototype); `aria-current` marks the active item. | README wins. |
| 2026-09-19 | M1 · Sidebar a11y | Key hints are aria-hidden and exposed through `aria-keyshortcuts`. The queue badge count is read through `aria-describedby` ("2 archives waiting"). The collapsed status dot is `role=img` with the status as its name. The toggle keeps focus across collapse/expand. | Clean accessible names. |
| 2026-09-19 | M1 · Contrast | Uses `ink-4` instead of the prototype's `ink-5` for the sidebar "Hangar …" line, the "Collapse sidebar [" button and the palette placeholder. `ink-5` (≈3.6:1 on bg-1) stays only on supplementary hints: sidebar key hints, palette kind column and footer. | WCAG AA 4.5:1 for real text and controls; README contrast table reserves ink-5 for hints. |
| 2026-09-19 | M1 · WT Live status | Shows "WT Live online" until M5 provides a skin count (`Sidebar.liveSkinCount`). The full "WT Live online · 2,318 skins" wraps to two lines in the 174px card, and does so in the prototype too. | No data before M5. |
| 2026-09-19 | M1 · Italian nav label | `common.nav.queue` in Italian is "Da installare". The screen title and the palette action keep "Coda di installazione". | "Coda di installazione" (126px) truncates next to a two-digit badge (99px available). The author may prefer other wording. |
| 2026-09-19 | M1 · Palette results | Action hints show the section shortcut (1–5, read from `SECTION_KEYS`) instead of the prototype's meaningless "Action". Empty query: 5 actions + 4 vehicles. Otherwise skins → vehicles → actions, case-insensitive substring on label or hint, max 9. Vehicles go to Explore (the vehicle filter arrives in M5), and skins arrive in M5. | README leaves the action hint open. |
| 2026-09-19 | M1 · Palette a11y | ARIA combobox + listbox (`aria-activedescendant`); rows are `role=option` divs, not tab stops. Tab is trapped in the input and focus returns to the opener on close. The input has no outline: the caret plus the highlighted row are the focus indicator in this modal. "No matches" sits in a `role=status` region outside the listbox. The overlay closes on mousedown on itself. | WAI-ARIA pattern; a listbox may only contain options. |
| 2026-09-19 | M1 · Escape layering | Escape inside the palette closes only the palette and stops propagation. Later menus, dialogs and zoom must also close only the topmost layer. | Avoid closing what is underneath. |
| 2026-09-19 | M1 · Toasts | Always-mounted `<section aria-live="polite">`; newest at the bottom; max 4, oldest dropped. Each toast's 6s timer pauses while hovered or focused and resumes with the time left. Keyboard Undo/× hands focus to the next toast or back to where it was. `undo()` runs at most once, never after expiry. | WCAG 2.2.1 (timing adjustable) and focus management. |
| 2026-09-19 | M1 · Ctrl+Z | **New shortcut**: Ctrl/Cmd+Z (outside text inputs) undoes the newest toast that offers Undo. | Keyboard users otherwise have to Tab to the end of the page within 6s. |
| 2026-09-19 | M1 · Drag & drop | Inside Tauri uses `onDragDropEvent` (real OS paths); in the browser falls back to HTML5 events (file names only). A drop with at least one ZIP/RAR/7z → items `analyzing` + switch to Install queue, no toast. A drop with no archive → "Only ZIP, RAR and 7z archives can be added" toast (the prototype's fake `dropped_archive.zip` fallback is not copied). A Tauri `enter` with no file paths does not show the overlay. The overlay also clears on window blur. TODO(M2): don't switch screens during first run. | Real paths are needed by `analyze_archive` (M4). |
| 2026-09-19 | M1 · Kbd / line-height | Kbd, the palette rows and the offline tag use `leading-[normal]` to match the prototype's `font:` shorthand (17px key cap, 35px palette rows). | 1:1 with the prototype. |
| 2026-09-19 | M1 · Motion | Hover color transitions (120ms) use `motion-safe:` variants, as does the toast enter animation (`toastIn`). | README Motion; instant under reduced motion. |
